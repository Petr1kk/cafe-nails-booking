# Запис на манікюр (2 майстри) — демо для портфоліо

Сайт (GitHub Pages) + «кухня» (Google Apps Script) + Google Календарі (по одному на майстра) + Google Таблиця для власника.
Основа: схема сайту запису на співбесіду (без її даних, ключів і адрес — код написано заново).

## Состав
- `docs/` — страница записи: `index.html`, `style.css`, `app.js` (экраны), `config.js` (адрес сервера), `demo.js` (демо-сервер в браузере), `core.js` (копия `Core.gs`).
- `apps-script/` — серверная часть: `Core.gs` (логика), `Code.gs` (календари, таблица, письма, API), `appsscript.json`.
- `tests/index.html` — тесты логики (открыть через `python -m http.server` в этой папке; заголовок вкладки покажет `PASS 29`).

## Демо-режим
Пока в `docs/config.js` пустой `API_URL`, сайт работает на выдуманных данных, записи хранятся только в браузере.
После правки `Core.gs` копию для сайта обновить: `copy apps-script\Core.gs site\core.js`.

## Подключение настоящего Google (≈ 20 минут, в своём Google-аккаунте)
1. Создать Google Таблицу → «Розширення → Apps Script».
2. Создать файлы `Core` и `Code` (содержимое из `apps-script/*.gs`), в настройках проекта показать `appsscript.json` и вставить содержимое.
3. Запустить `setup` и разрешить доступ. Появятся листы «Записи», «Спроби», «Налаштування», «Майстри», «Послуги» и два календаря «Манікюр: …».
4. В «Налаштування» указать «Пошта власника» и «Адреса сайту»; в «Майстри» — дни и часы, в «Послуги» — услуги и цены.
5. «Почати розгортання → Веб-застосунок», выполнять от своего имени, доступ «Усі». Адрес `…/exec` вставить в `docs/config.js` (`API_URL`).
6. Pages уже настроен на папку `docs/` этого репозитория (Settings → Pages).

## Правила для мастеров
- Личные записи вносить в свой календарь «Манікюр: <имя>»: событие любой длины закрывает время на сайте.
- Закрыть запись на сайте: «Налаштування → Прийом записів → ні».
